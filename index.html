Azərbaycan Texniki Universitetinin Kompüter Elmləri fakültəsinin məzunuyam və eyni zamanda Code Academy-də Full Stack Developer proqramını tamamlamışam. Akademik təhsil və praktiki kurs proqramları ilə kifayətlənməyərək, mühəndislik fəaliyyətimin nəzəri və tətbiqi təməlini müstəqil araşdırma metodologiyaları üzərində qurmuşam. Sənayenin qlobal miqyasda tanınan ekspertlərinin empirik yanaşmalarını mütəmadi analiz edir, qabaqcıl memarlıq (architecture) prinsiplərini öz mühəndislik həllərimdə tətbiq edirəm.

Hazırda fəaliyyətimi .NET Core ekosistemi üzrə ixtisaslaşmış Backend Developer olaraq davam etdirirəm. Proqram təminatının hazırlanması həyat dövrünün (SDLC) bütün struktur mərhələlərində aktiv rol alıram. Bura sadəcə proqramlaşdırma deyil, həmçinin sistem analizinin aparılması, müştəri tələblərinin konseptuallaşdırılması və funksional spesifikasiyaların təyini prosesləri daxildir. Layihələrin idarə edilməsində iki həftəlik sprint dövrlərinə əsaslanan Agile/Scrum metodologiyasını tətbiq edir, resursların qiymətləndirilməsi (estimation) və proqram təminatının optimallaşdırılmış şəkildə çatdırılması proseslərinə töhfə verirəm.

Texniki fəaliyyətimlə yanaşı, həvəskar dron pilotluğu , üzgüçülük və fotoqrafçılıq ilə məşğulam.
